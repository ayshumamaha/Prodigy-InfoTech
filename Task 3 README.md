# Markov Chain Text Generator

## Overview

The Markov Chain Text Generator is an AI-based text generation project that produces new text by analyzing patterns in existing text datasets. The system uses Markov Chain probability models to predict the next word based on previously observed sequences.

This project demonstrates probabilistic text generation and foundational Natural Language Processing concepts.

---

## Features

* Automated text generation
* Pattern-based sentence creation
* Probabilistic language modeling
* Training on custom text datasets
* Dynamic content generation
